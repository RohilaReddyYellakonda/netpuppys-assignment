
# Tulas International School Homepage

## Project Overview

A modern, responsive homepage redesign for Tulas International School.

## Technologies Used

- React.js
- Vite
- Framer Motion
- CSS3
- Lucide React

## Features

- Responsive homepage
- Animated hero section
- Scroll-triggered animations
- Dark and light theme
- Scroll progress indicator
- Responsive navigation
- Campus life section
- Academic section
- Admissions section
- Contact information

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project:

```bash
cd tis-homepage
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

This project can be deployed using Vercel or Netlify.

Build command:

```bash
npm run build
```

Output directory:

```text
dist
```
